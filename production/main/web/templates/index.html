⚔️ How to Connect & Duel on This Server

Our duel engine runs Project Ignis / ocgcore on TCP Port 7911. Any player with EDOPro, YGOPro, or Omega can connect directly!

  1. Download Custom Expansion Package

    Download custom_cards.cdb and Lua scripts to see all custom card images, effects, and passcodes.

    Download custom_cards.cdb Download Lua Scripts (.zip)
  2. Place in your EDOPro expansions/ folder

    Copy custom_cards.cdb into your EDOPro expansions/ directory. Copy effect scripts into expansions/script/.

  3. Connect to Port 7911 in EDOPro

    In EDOPro, click Multiplayer ➔ Duel Online (Direct Connect):

    Host / IP: duel.yourdomain.com | Port: 7911
